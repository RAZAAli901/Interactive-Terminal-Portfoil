## 🖥️ Project Overview
This project is a developer portfolio designed as a functional Windows-style desktop environment. Users can interact with draggable icons, run terminal commands, and browse files through a custom UI.

## ✨ Key Features
* **Desktop Environment**: Features draggable icons and a functional taskbar.
* **Live Terminal**: A functional command-line interface to navigate the portfolio.
* **File Explorer**: A "My Computer" window acting as a file system browser.
* **Start Menu**: Classic Windows-style menu for navigation and app launching[cite: 2].
* **12 Wallpapers**: Includes a built-in switcher with space, gaming, and landscape themes[cite: 2].
* **Loading Screen**: A custom boot animation that triggers on initial load[cite: 2].

## 🛠️ Tech Stack
* **React 19**: Core frontend framework[cite: 2].
* **Vite**: Modern build tool and development server[cite: 2].
* **CSS Modules**: For scoped and maintainable styling[cite: 2].
* **JavaScript**: Core logic for the terminal and OS simulation[cite: 2].

## 💻 Terminal Commands
You can control the portfolio using the following terminal commands[cite: 2]:

| Command | Description |
| :--- | :--- |
| `help` | List all available commands[cite: 2] |
| `about` | Display information about RAZA Ali[cite: 2] |
| `projects` | View a gallery of my latest projects[cite: 2] |
| `contact` | Show social and contact details[cite: 2] |
| `wallpaper [1-12]` | Instantly change the desktop background[cite: 2] |
| `clear` | Clear the terminal history[cite: 2] |
